# Оценки жюри ЗКНП — полный гайд

Как это устроено: **один ноутбук — сервер** (на нём программа и все данные), **остальные ноутбуки жюри — просто браузер**. Все в одной Wi‑Fi сети, интернет не нужен.

```
 Ноутбук-сервер (организатор)          Ноутбуки жюри
 ┌───────────────────────────┐   Wi‑Fi   ┌──────────────┐
 │ node server.js            │◄─────────►│ браузер      │ Жюри 1
 │ пульт: localhost:8080/admin│          └──────────────┘
 │ данные: jury-server/data  │◄─────────►  …  Жюри 2, 3 …
 └───────────────────────────┘
```

---

## 1. Сервер: установка

### ⚡ Linux и macOS — одной командой, без sudo
Подходит и для учебного профиля, где `sudo` «не найдена». Скачивает Node.js в домашнюю папку, ставит программу в `~/jury-scores`, кладёт ярлык «Сервер жюри» на Рабочий стол, проверяет и запускает сервер:
```bash
curl -fsSL https://raw.githubusercontent.com/qwerty-ll/jury-scores/main/install.sh | bash
```
Если `curl` нет:
```bash
wget -qO- https://raw.githubusercontent.com/qwerty-ll/jury-scores/main/install.sh | bash
```
Потом запускать двойным щелчком по ярлыку «Сервер жюри» или командой `bash ~/jury-scores/start-server.sh`. Повторный запуск установщика обновляет программу и **не трогает** оценки, пароль и PIN.

> Учебный профиль может очищаться при выходе из системы. Во время конкурса не выходите из профиля и вставьте флешку — копии пишутся на неё сами.

Ниже — установка вручную (и для Windows).

### Windows (PowerShell)
```powershell
# 1. Node.js (после установки закрыть и открыть PowerShell заново)
winget install OpenJS.NodeJS.LTS

# 2. Проект — с git:
git clone https://github.com/qwerty-ll/jury-scores.git
#    или без git:
Invoke-WebRequest https://github.com/qwerty-ll/jury-scores/archive/refs/heads/main.zip -OutFile jury.zip; Expand-Archive jury.zip -DestinationPath .; Rename-Item jury-scores-main jury-scores

# 3. Открыть порт 8080 (один раз, PowerShell «от имени администратора»)
New-NetFirewallRule -DisplayName "Jury Scores 8080" -Direction Inbound -LocalPort 8080 -Protocol TCP -Action Allow
```
Если `winget` нет — скачать установщик LTS с https://nodejs.org.

### Linux (Ubuntu / Debian)
```bash
# 1. Node.js 20 (в Ubuntu 22.04 штатный пакет слишком старый)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - && sudo apt install -y nodejs git

# 2. Проект
git clone https://github.com/qwerty-ll/jury-scores.git

# 3. Порт (только если включён ufw)
sudo ufw allow 8080/tcp
```

### macOS
```bash
brew install node        # или установщик с https://nodejs.org
git clone https://github.com/qwerty-ll/jury-scores.git
```

### Проверка, что всё встало
```bash
cd jury-scores
node -v                  # должно быть v16 или новее
node tests/run.mjs       # должно быть «28 из 28 проверок прошли»
```

## 2. Сервер: запуск

| Система | Команда (из папки `jury-scores`) | Или двойной щелчок |
|---|---|---|
| Windows | `node jury-server\server.js` | `jury-server\Запустить_Windows.bat` |
| Linux | `node jury-server/server.js` | `jury-server/Запустить_Linux.sh` |
| macOS | `node jury-server/server.js` | `jury-server/Запустить.command` |

> На Windows пишите `node …`, а не `npm start`: PowerShell часто блокирует `npm`.

В окне появится:
```
Пульт организатора (на этом ПК): http://localhost:8080/admin
Пароль организатора:             906231
Адрес для ноутбуков и планшетов жюри:
    http://192.168.137.1:8080
PIN судей:
    Жюри 1   0287
    ...
```
**Окно не закрывать до конца конкурса.** Остановить — `Ctrl+C`. При повторном запуске все данные, пароль и PIN сохраняются.

Свой пароль организатора (действует только при самом первом запуске, пока нет папки `data`):
```powershell
$env:ADMIN_PASSWORD="123456"; node jury-server\server.js     # Windows
```
```bash
ADMIN_PASSWORD=123456 node jury-server/server.js             # Linux / macOS
```
Если порт 8080 занят — `PORT=8081` так же, как пароль (тогда и у жюри адрес с `:8081`).

## 3. Сеть

Любой из вариантов — главное, чтобы сервер и жюри были в **одной** сети.

**А. Роутер или телефон в режиме модема** — самый надёжный. Подключить к нему и сервер, и всех жюри.

**Б. Раздача Wi‑Fi с ноутбука-сервера:**
* **Windows:** Параметры → Сеть и Интернет → Мобильный хот‑спот → Вкл. Адрес сервера будет `192.168.137.1`. Без интернета хот‑спот иногда не включается — тогда вариант А.
* **Linux:**
  ```bash
  nmcli device wifi hotspot ssid JURY password 12345678
  ```
  Адрес сервера будет `10.42.0.1`. Выключить: `nmcli connection down Hotspot`.
* **macOS:** Системные настройки → Основные → Общий доступ → Общий доступ к интернету: «Общий доступ к подключению» — любой интерфейс (например, Мост Thunderbolt), «через» — Wi‑Fi. Адрес обычно `192.168.2.1`.

## 4. Сервер: чтобы не уснул

Сервер сам запрещает сон, пока работает. Крышку закрывать нельзя, кроме Linux. На Windows разрешить закрытую крышку от сети (командная строка от администратора):
```powershell
powercfg /setacvalueindex SCHEME_CURRENT SUB_BUTTONS LIDACTION 0
powercfg /setactive SCHEME_CURRENT
```
Вернуть «сон при закрытии крышки» после конкурса: то же самое с `1` вместо `0`.

Ноутбук-сервер держать **на зарядке**.

## 5. Ноутбуки жюри

Ничего устанавливать не нужно — только **Chrome, Edge или Firefox**.

1. Подключиться к той же Wi‑Fi сети.
2. Открыть адрес из окна сервера, например `http://192.168.137.1:8080`.
3. Ввести PIN (кнопками или с клавиатуры).
4. На весь экран — `F11`.

### Режим киоска (жюри не уйдёт с экрана; выход — `Alt+F4`)
```powershell
start chrome --kiosk http://192.168.137.1:8080                                  # Windows, Chrome
start msedge --kiosk http://192.168.137.1:8080 --edge-kiosk-type=fullscreen     # Windows, Edge
```
```bash
google-chrome --kiosk http://10.42.0.1:8080     # Linux, Chrome
firefox --kiosk http://10.42.0.1:8080           # Linux, Firefox
```

### Найти адрес сервера автоматически
Нужна папка проекта на ноутбуке жюри (п. 1, без Node.js):
```powershell
powershell -ExecutionPolicy Bypass -File connect-jury.ps1      # Windows
```
```bash
bash connect-jury.sh                                           # Linux / macOS
```
Скрипт найдёт сервер, откроет браузер и положит ярлык на Рабочий стол.

### Чтобы экран жюри не гас
```powershell
powercfg /change monitor-timeout-ac 0; powercfg /change standby-timeout-ac 0     # Windows
```
```bash
gsettings set org.gnome.desktop.session idle-delay 0                                       # Linux (GNOME)
gsettings set org.gnome.settings-daemon.plugins.power sleep-inactive-ac-type 'nothing'
```
Если ноутбук всё-таки уснул или пропал Wi‑Fi — оценки не теряются: они хранятся в браузере и дойдут сами (вверху экрана видно «ждут отправки»).

## 6. Подготовка накануне

1. Запустить сервер, открыть пульт `http://localhost:8080/admin`, ввести пароль.
2. **Настройка и Бэкап → Судьи:** «+ Судья» до нужного числа, вписать имена.
3. **Судьи:** раздать PIN (распечатать или записать).
4. **Настройка и Бэкап → Постановки:** проверить порядок и названия.
5. Подключить все ноутбуки жюри, у каждого ввести его PIN. Во вкладке «Судьи» у всех должна гореть зелёная точка.
6. Прогнать одну постановку: «Начать отсчёт» → оценки → «Отправить» → «Закончить отсчёт» → посмотреть «Итоги».
7. **Настройка и Бэкап → «Стереть все оценки и время».**
8. Флешка: на macOS и Linux подхватывается сама. На Windows создать на ней папку:
   ```powershell
   mkdir E:\jury-backup        # E: — буква флешки
   ```

Начать полностью с нуля (новый пароль и новые PIN, **все данные удаляются**):
```powershell
Remove-Item -Recurse -Force jury-server\data     # Windows
```
```bash
rm -rf jury-server/data                          # Linux / macOS
```

---

## 7. Во время конкурса

* **Сцена:** выбрать постановку → «Начать отсчёт» → «Закончить отсчёт». У жюри постановка переключается сама.
* Там же видно, кто отправил оценки. Когда все отправили — кнопка «Переключить на следующую».
* Жюри ошибся после отправки — «Разрешить исправить».
* Жюри «выкинуло» — пусть снова введёт свой PIN, оценки на месте.
* Сервер случайно закрыли — запустить той же командой, всё на месте.

## 8. После конкурса

* **Итоги → «Скачать таблицу (Excel / CSV)»** и **«Протокол для печати»** (с местами для подписей).
* Все файлы: `jury-server/data/` — `state.json` (данные), `journal.jsonl` (журнал каждого нажатия), `backups/` (копии). На флешке — папка `jury-backup`.

---

## 9. Если сервер-ноутбук сломался

**Способ 1 — скопировать папку.** Скопировать `jury-server/data` (или `jury-backup` с флешки, переименовав `state-latest.json` в `state.json`) в `jury-server/data` на новом ноутбуке и запустить. Пароль, PIN и оценки — те же.

**Способ 2 — через пульт.** На старом: «Скачать файл копии». На новом: запустить сервер, войти, «Восстановить из копии». После восстановления пароль организатора станет таким, как был на старом сервере.

В обоих случаях у нового сервера **другой адрес** — жюри открывают новый адрес и снова вводят свой PIN.

## 10. Если что-то не работает

| Проблема | Что сделать |
|---|---|
| Жюри не открывает адрес | Та же Wi‑Fi сеть? Порт открыт (п. 1, шаг 3)? На Windows при вопросе брандмауэра отметить **обе** галочки. |
| В окне сервера несколько адресов | Брать тот, что из сети Wi‑Fi (`192.168.…` или `10.42.…`), не `198.18.…` (это VPN). |
| `node` не найден | Закрыть и открыть терминал после установки Node.js. |
| Windows: «выполнение сценариев отключено» | Запускать `node jury-server\server.js` вместо `npm start`; для `.ps1` — с `-ExecutionPolicy Bypass`. |
| «Порт 8080 занят — пробую 8081» | Порт занят другой программой — сервер сам взял следующий. Жюри открывают адрес **с новым портом** из окна сервера. |
| «Сервер жюри УЖЕ запущен» | Он уже работает в другом окне — второй не нужен, ищите то окно. |
| «Слишком много попыток» | 5 неверных PIN подряд — подождать минуту. |
| В журнале «Журнал изменён вручную» | Кто-то правил файл `journal.jsonl` руками. Оценки — в `state.json` и копиях. |
| Сервер пишет, что `state.json` повреждён | Он сам поднимет последнюю копию. Если копий нет — взять `state-latest.json` с флешки (п. 9). |
