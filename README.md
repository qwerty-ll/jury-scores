# Оценки жюри ЗКНП (`jury-scores`)

Автономная веб-система оценивания выступлений для жюри и организаторов (работает на **любых ноутбуках Windows / macOS / Linux**, планшетах и смартфонах, не требует интернета и внешних библиотек — нужен только Node.js).


📘 **Полный гайд: установка, запуск, сеть, подключение жюри, все команды — [ГАЙД.md](ГАЙД.md).**

---

## 🎯 Критерии ЗКНП (максимум 32 балла)

Критерии **1–6** выставляются членами жюри по шкале **от 0 до 5 включительно** (максимум **30 баллов** от судьи):
1. **Идея и сценарий** *(Цельность замысла, связь с темой, логика сюжета)* — `0–5`
2. **Актерское мастерство** *(Выразительность, сценическая речь, уверенность на сцене)* — `0–5`
3. **Музыкальное оформление** *(Музыка, её связь с сюжетом)* — `0–5`
4. **Визуальное оформление** *(Декорации и свет, их связь с сюжетом)* — `0–5`
5. **Костюмы и образы** *(Соответствие персонажам и сюжету)* — `0–5`
6. **Общее впечатление** *(Эмоциональный отклик, запоминаемость)* — `0–5`

Критерий **7 — Тайминг** (выставляется **автоматически** по таймеру сцены):
* **2 балла** — постановка до 15 минут включительно (`≤ 15:00`)
* **1 балл** — постановка 16–17 минут (`15:01 – 17:00`)
* **0 баллов** — постановка более 17 минут (`> 17:00`)

**Итоговый балл постановки** = среднее арифметическое сумм судей (до 30) + балл за тайминг (до 2) = **максимум 32 балла**.

## 🚀 Быстрый запуск (1 команда)

### 1. На главном ноутбуке (Сервер — Mac / Windows / Linux)
Linux / macOS, без sudo (в том числе учебный профиль):
```bash
curl -fsSL https://raw.githubusercontent.com/qwerty-ll/jury-scores/main/install.sh | bash
```
Или вручную:
```bash
git clone https://github.com/qwerty-ll/jury-scores.git && cd jury-scores && npm start
```
*(Либо двойной клик по `jury-server/Запустить.command` на Mac, `jury-server/Запустить_Windows.bat` на Windows или `./jury-server/Запустить_Linux.sh` на Linux).*

В терминале сразу появятся:
* **Пульт организатора:** `http://localhost:8080/admin` и **Пароль организатора**
* **Адрес для ноутбуков/планшетов жюри:** например `http://192.168.1.45:8080`
* **4-значные PIN-коды судей**

### 2. На ноутбуках / планшетах жюри (Клиенты)
Ничего устанавливать **не нужно**!
1. Подключиться к той же Wi‑Fi сети (роутер в зале, хотспот телефона или раздача с главного ноутбука).
2. Открыть в любом браузере (Chrome / Safari / Edge) адрес из терминала: `http://<IP-сервера>:8080`
3. Ввести свой 4-значный PIN (можно с клавиатуры ноутбука или кнопками на экране).

## 🛡 Многоуровневая защита и автобэкап

1. **Мгновенная запись каждого клика:** каждое нажатие оценки сразу записывается на диск через атомарный `fsync` (`data/state.json`) и в криптографический журнал (`data/journal.jsonl` с цепочкой SHA-256).
2. **Мгновенный бэкап при нажатии «Отправить оценки»:** как только судья нажимает «Отправить», и отдельно — **как только все судьи нажали «Отправить» по постановке**, сервер мгновенно сохраняет именную резервную копию (`state.json` + готовую таблицу `results-latest.csv`).
3. **Периодический бэкап:**
   * Каждую **1 минуту** (при наличии любых изменений).
   * Каждые **15 минут** — гарантированный полный срез состояния и CSV-таблицы.
4. **Автокопирование на флешку:** если в серверный ноутбук вставлена флешка (на macOS в `/Volumes/*`, на Windows папка `D:\jury-backup` / `E:\jury-backup`, на Linux `/media/*`), все копии параллельно дублируются на неё.
5. **Оффлайн-очередь у судей:** если у ноутбука/планшета судьи пропал Wi‑Fi, оценки хранятся в `localStorage` браузера и автоматически досылаются при появлении связи.
6. **Быстрая замена главного сервера:** во вкладке «Настройка и Бэкап» есть кнопки **«Скачать файл копии (state.json)»** и **«Восстановить из копии»** — можно за 5 секунд перенести весь конкурс на другой ноутбук.
