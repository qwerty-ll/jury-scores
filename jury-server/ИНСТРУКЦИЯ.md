# Оценки жюри ЗКНП — инструкция организатора

## 1. Кто является главным сервером?
Главным сервером может быть **абсолютно любой ноутбук** (Windows, macOS или Linux) на котором установлен [Node.js](https://nodejs.org), либо облачный VPS.

### 3 лучших варианта организации сети в зале:
1. **Через отдельный Wi‑Fi роутер (самый надёжный вариант для зала):**
   * Поставьте на стол жюри любой обычный домашний Wi‑Fi роутер (интернет-кабель в него втыкать **не нужно**).
   * Подключите к этому роутеру главный ноутбук-сервер и ноутбуки/планшеты судей.
2. **Точка доступа (Мобильный хотспот) с Windows или Mac ноутбука:**
   * **На Windows 10/11:** *Параметры → Сеть и Интернет → Мобильный хотспот → Вкл.*
   * **На Mac:** *Системные настройки → Основные → Общий доступ → Общий доступ к интернету (через Wi‑Fi).*
3. **Раздача Wi‑Fi с телефона организатора:**
   * Включите режим модема на телефоне, подключите к нему ноутбук-сервер и устройства судей.

---

## 2. Как запустить сервер и подключить клиентов

### На сервере (любой ноутбук Mac / Windows / Linux):
Выполните в терминале (или PowerShell на Windows):
```bash
git clone https://github.com/qwerty-ll/jury-scores.git && cd jury-scores && npm start
```
Либо дважды кликните:
* На macOS: `jury-server/Запустить.command`
* На Windows: `jury-server/Запустить_Windows.bat`

### На ноутбуках и планшетах жюри (клиенты):
Ничего скачивать не нужно:
1. Подключитесь к общему Wi‑Fi.
2. Откройте в браузере адрес, который написан в окне сервера (например, `http://192.168.1.10:8080`).
3. Введите 4-значный PIN судьи (работает ввод с клавиатуры ноутбука и нажатие мышкой/пальцем).

---

## 3. Как работают бэкапы (ничего не пропадёт)
* **При каждом клике:** данные сразу пишутся в `jury-server/data/state.json` и `journal.jsonl`.
* **После нажатия «Отправить оценки»:** каждый раз, когда судья отправляет лист, и **отдельно когда все судьи отправили оценки по выступлению**, сервер мгновенно делает полный бэкап JSON + CSV-таблицы в `jury-server/data/backups/`.
* **По таймеру:** каждую **1 минуту** при изменениях и **каждые 15 минут** принудительно.
* **На флешку:** вставьте флешку в ноутбук-сервер (на Windows создайте на флешке папку `jury-backup`), и сервер будет автоматически дублировать туда все файлы и актуальную Excel/CSV таблицу.

## 4. Памятка по системам

### Сервер (ноутбук организатора)
| | Windows | Linux | macOS |
|---|---|---|---|
| Запуск | `Запустить_Windows.bat` (первый раз — правой кнопкой → «Запуск от имени администратора», чтобы открыть порт 8080) | `./Запустить_Linux.sh` | `Запустить.command` |
| Сон | отключается сервером сам | отключается сервером сам, включая закрытие крышки | отключается сервером сам |
| Крышка | **Панель управления → Электропитание → Действие при закрытии крышки → «Действие не требуется»** (от сети) | работает и с закрытой крышкой | держать открытой |
| Брандмауэр | на вопрос про Node.js отметить **обе** галочки и «Разрешить» | если включён ufw: `sudo ufw allow 8080/tcp` | «Разрешить входящие подключения» |
| Раздача Wi‑Fi | Параметры → Сеть и Интернет → Мобильный хот‑спот (адрес сервера будет `192.168.137.1`) | Настройки → Wi‑Fi → «Включить точку доступа» (адрес обычно `10.42.0.1`) | Общий доступ к интернету (`192.168.2.1`) |

Хот‑спот Windows иногда не включается без интернета, а Wi‑Fi адаптер на Linux может не уметь раздавать. Если раздача не запускается — роутер или телефон в режиме модема.

### Ноутбуки жюри (любая система)
* Ничего ставить не нужно — только браузер: **Chrome, Edge или Firefox** свежей версии. Internet Explorer не подойдёт.
* Открыть адрес сервера, ввести PIN (можно с клавиатуры), нажать **F11** — полноэкранный режим.
* Отключить сон экрана на время конкурса (или хотя бы 30 минут). Если ноутбук всё же уснул — оценки не пропадут, после пробуждения дойдут сами.
* Адрес можно найти автоматически:
  * Windows: `powershell -ExecutionPolicy Bypass -File connect-jury.ps1`
  * Linux / macOS: `bash connect-jury.sh`

  Скрипт сам найдёт сервер в сети, откроет браузер и положит ярлык на Рабочий стол.
* Не меняйте сеть и адрес сервера посреди конкурса: браузер хранит вход и неотправленные оценки отдельно для каждого адреса.

## 5. Проверка перед конкурсом
`npm test` — 30 автоматических проверок сервера (вход, оценки, блокировка, тайминг, бэкапы, восстановление, журнал, перезапуск). Должно быть «30 из 30 проверок прошли».
